# Picasso Ops 첫 스타일 적용

2026년 10월 10일. 파란색 기반 브랜드와 Pretendard 자체 제공 폰트를 적용했습니다.

## 변경 범위

- 왼쪽 탐색, 상단 모드·사용자, 화면 제목과 설명, 모의 현장 표시.
- 독자적인 SVG 워드마크 심볼과 탐색 아이콘. 폰트의 저작권·OFL 고지는 public/fonts/LICENSE.txt.
- 입력·버튼·표·알림·관측·사람 판단·복원 보고의 공통 표현.
- 로봇 목록과 상세는 위에, 어댑터와 프로파일은 전체 폭의 아래 구역으로 배치.
- 넓은 표는 키보드로 접근할 수 있는 가로 스크롤 영역에 배치.
- 모바일에서는 탐색을 위에 두고 콘텐츠를 한 열로 표시.

## 보존한 의미와 후속 범위

메뉴 순서·기본 화면·모드 제한·API·판정 로직·표 열 순서를 유지합니다. 조작 결과 알림은 중립색으로 표시하고 글자로 결과 모름·거부·성공을 구분합니다. 파란색은 주요 행동과 선택에 사용합니다. 선택된 보류 행은 선택과 보류를 함께 표현합니다.

URL 탐색, 초안 보존, 운영 개요 집계, 하위 탭, 판단 확인 대화상자는 후속 UX 작업입니다. 첫 스타일 적용이 전체 개편 구현 완료를 의미하지 않습니다. 화면설계서 §4.3의 24행 CSS 및 기존 스크린샷은 이전 기준선이며 현재 시각 표현은 이 변경과 styles.css를 따릅니다. 기존 65장 촬영본은 재촬영 전 자료입니다.

## 후속 UX 반영

같은 날짜의 [로봇 도입 여정 개편](onboarding-refresh.md)에서 메뉴·하위 화면·입력 보존을 변경했습니다. 위의 보존 범위와 후속 항목은 첫 스타일 적용 시점의 기록입니다. 현재 동작은 후속 문서를 우선합니다.
